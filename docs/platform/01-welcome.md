# ברוכים הבאים

**אתר הבית של גדוד אלון** הוא פורטל: כל כלי (לו"ז כביסה, ריכוז חוסרים, לומדות…) הוא **אפליקציה** בתוך האתר.
המשתמשים מתחברים פעם אחת, וכל אפליקציה יודעת מי הם — בלי שתצטרכו לבנות התחברות, משתמשים או מסד נתונים.

אתם בונים אפליקציה (לבד או עם ChatGPT / Claude), שולחים אותה כ-**Pull Request** ב-GitHub, ואחרי בדיקה היא עולה לאתר.

## שתי רמות של אפליקציה

| | **פשוטה** (`simple`) | **מלאה** (`full`) |
|---|---|---|
| ממה בנויה | HTML + JavaScript רגיל | דף Next.js + TypeScript (React) |
| איך מדברת עם הפורטל | `<script src="/bahad.js">` → האובייקט `bahad` | `import { bahad } from "@/platform/client"` |
| איפה רצה | בתוך iframe נעול (sandbox) | כדף רגיל בתוך האתר |
| בדיקה מקומית | פותחים את `index.html` בדפדפן (מצב פיתוח) | `pnpm dev` (משתמשים מדומים) |
| מתאים ל… | כמעט הכל: טפסים, רשימות, לומדות, לוחות | אפליקציות גדולות עם הרבה מסכים |

**כלל אצבע: התחילו בפשוטה.** אותו API בדיוק זמין בשתי הרמות, כך שמעבר בהמשך קל.

## מה מקבלים מהפורטל
- **משתמש:** שם ותמונה; לפי בקשה גם תפקיד (חניך/מפקד/מנהל), פלוגה ומחלקה; ובאישור מיוחד אימייל/טלפון.
- **שמירת נתונים:** "אוספים" (collections) מבודדים לכל אפליקציה, עם חוקי גישה פשוטים (רק אני / המחלקה / הפלוגה / כולם).
- **עדכון חי:** האפליקציה מקבלת סימן כשמשהו השתנה באוסף.
- **התראות לטלפון** (push), גם מתוזמנות.
