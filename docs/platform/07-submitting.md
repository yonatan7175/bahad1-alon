# שליחת האפליקציה

## דרך GitHub (מומלץ)
1. **Fork:** בדף הריפו ב-GitHub לוחצים **Fork** (למעלה בצד ימין) — נוצר עותק בחשבון שלכם.
2. **מוסיפים את התיקייה:** בעותק שלכם, נכנסים לתיקייה `apps/` ← **Add file** ← **Upload files**, וגוררים את תיקיית האפליקציה (`<slug>/` עם `app.json`, `icon.svg`, `README.md` ו-`site/`).
   אפליקציה מלאה: עובדים מקומית (`git clone` של ה-fork, `pnpm install`, `pnpm dev`) ודוחפים (`git push`).
3. **Pull Request:** GitHub יציע **Contribute → Open pull request**. ממלאים את התבנית: מה האפליקציה עושה, צילומי מסך מהטלפון, אילו הרשאות ולמה.
4. **בדיקות:** תוך כמה דקות יופיעו תוצאות הבדיקות האוטומטיות (✔ / ✖). אם משהו נכשל — לוחצים על **Details**, מתקנים ומעלים שוב לאותו branch.
5. **קישור תצוגה מקדימה** (Vercel preview) יופיע ב-PR — המנהל בודק בו את האפליקציה בטלפון.
6. אחרי אישור ומיזוג — האפליקציה עולה לאתר אוטומטית.

## בלי GitHub
שולחים למנהל את התיקייה כקובץ **zip** (עם `app.json`, `icon.svg`, `README.md`, `site/`). המנהל יפתח את ה-PR בשבילכם.

## צ'קליסט לפני שליחה
- [ ] `slug` זהה לשם התיקייה; `version` עלה
- [ ] נבדק בטלפון (רוחב 360px), בעברית, מימין לשמאל
- [ ] אין תוכן אסור ([החוקים](/dev/rules)), אין בקשות לשרתים חיצוניים
- [ ] הרשאות מינימליות; `contact`/`push` מוסברות ב-README
- [ ] `authors` כולל את שם המשתמש שלכם ב-GitHub
