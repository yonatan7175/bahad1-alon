# add-app — הוספת אפליקציה (v1)

כל משתמש מאושר מציע תוספת לפורטל; **מנהל האתר מאשר או דוחה** כל הצעה.

## שתי דרכים
- **אתר (קישור):** כתובת `https://`, שם, תיאור ואייקון. אחרי אישור — אריח חדש בדף הבית (תגית "קישורים") שפותח את האתר **בלשונית חדשה**. האתר לא מוטמע בפורטל ולא מקבל גישה ל-Platform API או לפרטי המשתמשים.
- **מאגר GitHub:** קישור `https://github.com/<owner>/<repo>`. אחרי אישור הקישור **רק נשמר** ברשימת "מאגרי GitHub שאושרו" שמנהל האתר רואה — שום קוד לא נבנה או מורץ.

## מסך הניהול (מנהלי האתר)
באותה אפליקציה, מתחת לטופס: ממתינות לאישור (אישור/דחייה + הערה למציע), אתרים שבדף הבית (הסרה), מאגרי GitHub (הסרה). בדף הבית מופיעה למנהל התראה כשיש הצעות ממתינות. כל החלטה נרשמת ב-`audit_log`.

## מגבלות
- עד 5 הצעות ממתינות למשתמש; אותו קישור לא מוצע פעמיים (אלא אם נדחה).
- `https` בלבד, בלי כתובות IP, בלי `user:pass@`. קישורי github.com — רק דרך אפשרות GitHub.

## מימוש
זו אפליקציה של **הליבה** (לא דרך `bahad.data`), כי האישור צריך לשנות את דף הבית: טבלה `public.app_submissions` (`supabase/migrations/20261120000005_app_submissions.sql`), פעולות שרת ב-`src/app/a/add-app/actions.ts`, אימות ב-`src/lib/submissions.ts`.
