# add-app — הוספת אפליקציה (v1)

כל משתמש מאושר מציע תוספת לפורטל; **מנהל האתר מאשר או דוחה** כל הצעה.

## שתי דרכים
- **אתר (קישור):** כתובת `https://`, שם, תיאור ואייקון. אחרי אישור — אריח חדש בדף הבית (תגית "קישורים") שפותח את האתר **בתוך הפורטל**, במסגרת של אפליקציה רגילה (`/l/<id>/<host>`: פס עליון, ⋮ → "על האפליקציה" / "פתיחה בלשונית חדשה"). אתר שחוסם הצגה בתוך אתר אחר נפתח **בלשונית חדשה**. בשני המקרים האתר לא מקבל גישה ל-Platform API או לפרטי המשתמשים.

## פתיחה בתוך הפורטל
- **בדיקה אוטומטית** (בשליחה, באישור, ובכפתור "בדיקה מחדש"): השרת פונה לאתר פעם אחת וקורא רק את הכותרות — `X-Frame-Options` ו-`frame-ancestors` (CSP אוכף בלבד). נשמרים הכתובת הסופית אחרי הפניות (`embed_url`) והסיבה (`embed_note`).
- **הגנת SSRF:** רק `https`, בלי כתובות IP ובלי `user:pass@`; כל כתובת שהשם מתפענח אליה חייבת להיות ציבורית (נבדק בתוך ה-DNS lookup של החיבור עצמו), עד 5 הפניות, מגבלת זמן כוללת.
- **בחירת מנהל:** "אוטומטי" (לפי הבדיקה) / "תמיד בתוך האתר" / "תמיד בלשונית" (`embed_mode`). "בדיקה מחדש של כל האתרים" — לאתרים שאושרו לפני שהתכונה נוספה.
- **אבטחה:** ה-iframe הוא `EXTERNAL_APP_SANDBOX` (המקור של האתר עצמו — לא של הפורטל), `referrerpolicy=no-referrer`. ה-proxy מתיר `frame-src` רק לדף `/l/<id>/<host>` ורק ל-`https://<host>` מהנתיב; הדף מציג מסגרת רק כשה-host תואם לרשומה המאושרת (אחרת מפנה לכתובת הנכונה), כך שנתיב מזויף לא יכול למסגר אתר אחר. בדיקות: `tests/unit/embed.test.ts`, `tests/e2e/links.spec.ts`.
- **מאגר GitHub:** קישור `https://github.com/<owner>/<repo>`. אחרי אישור הקישור **רק נשמר** ברשימת "מאגרי GitHub שאושרו" שמנהל האתר רואה — שום קוד לא נבנה או מורץ.

## מסך הניהול (מנהלי האתר)
באותה אפליקציה, מתחת לטופס: ממתינות לאישור (אישור/דחייה + הערה למציע), אתרים שבדף הבית (הסרה), מאגרי GitHub (הסרה). בדף הבית מופיעה למנהל התראה כשיש הצעות ממתינות. כל החלטה נרשמת ב-`audit_log`.

## מגבלות
- עד 5 הצעות ממתינות למשתמש; אותו קישור לא מוצע פעמיים (אלא אם נדחה).
- `https` בלבד, בלי כתובות IP, בלי `user:pass@`. קישורי github.com — רק דרך אפשרות GitHub.

## מימוש
זו אפליקציה של **הליבה** (לא דרך `bahad.data`), כי האישור צריך לשנות את דף הבית: טבלה `public.app_submissions` (`supabase/migrations/20261120000005_app_submissions.sql`, עמודות `embed_*` ב-`…000007_link_embed.sql`), בדיקת ההטמעה ב-`src/lib/embed.ts` + `src/platform/server/embed-probe.ts`, פעולות שרת ב-`src/app/a/add-app/actions.ts`, אימות ב-`src/lib/submissions.ts`.
